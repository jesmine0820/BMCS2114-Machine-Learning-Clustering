# 🌱 Text Clustering on Sustainability-Related Documents

**BMCS2114 — Machine Learning Assignment**

An unsupervised machine learning project focused on performing **text clustering on sustainability-related documents**. The project aims to discover hidden patterns, similarities, and thematic relationships among sustainability-related news articles using machine learning clustering techniques.

The dataset is obtained from Kaggle, containing Guardian environment-related news articles. Text preprocessing and clustering algorithms are applied to group documents based on their textual characteristics.

---

## 🎯 Project Objectives

- Explore and analyze sustainability-related news documents.
- Preprocess textual data for machine learning applications.
- Apply unsupervised learning techniques to identify document clusters.
- Compare different clustering algorithms and their performance.
- Deploy trained clustering models for interactive use.

---

## 📂 Dataset

**Source:** [Guardian Environment-Related News Dataset — Kaggle](https://www.kaggle.com/datasets/beridzeg45/guardian-environment-related-news)

The dataset contains environment-related news articles from The Guardian, which are used as the foundation for our text clustering task.

**Main purpose of the dataset:**

## 🔬 Machine Learning Approaches

This project explores two unsupervised clustering algorithms:

| Algorithm | Approach | Main Characteristic |
|---|---|---|
| **Fuzzy C-Means (FCM)** | Soft Clustering | Each document can belong to multiple clusters with different membership degrees. |
| **Gaussian Mixture Model (GMM)** | Probabilistic Clustering | Each document is assigned probabilities of belonging to different Gaussian components. |

Both approaches are used to explore different ways of identifying patterns and relationships within sustainability-related documents.

## 📈 Project Workflow

The general workflow of the project consists of:

1. **Data Collection** – Obtain sustainability-related news articles from Kaggle.
2. **Text Preprocessing** – Clean and prepare textual data for analysis.
3. **Feature Extraction** – Transform text into numerical representations.
4. **Model Training** – Train Fuzzy C-Means and Gaussian Mixture Model.
5. **Clustering Analysis** – Examine the resulting document clusters.
6. **Model Deployment** – Deploy the trained models for interactive use.
